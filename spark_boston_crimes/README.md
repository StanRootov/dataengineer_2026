# Витрина статистики преступлений в Бостоне

Домашнее задание по Apache Spark.

Программа строит агрегированную витрину статистики преступлений по районам Бостона на основе датасета [Crimes in Boston](https://www.kaggle.com/datasets/AnalyzeBoston/crimes-in-boston).

## Результат

Итоговая витрина содержит одну строку на район и следующие поля:

| Поле | Описание |
|---|---|
| `district` | код района |
| `crimes_total` | общее количество преступлений |
| `crimes_monthly` | медиана количества преступлений в месяц |
| `frequent_crime_types` | три наиболее частых типа преступлений |
| `lat` | средняя широта инцидентов |
| `lng` | средняя долгота инцидентов |

Результат сохраняется в формате Parquet.

## Обработка данных

Перед построением витрины выполняется очистка исходных данных:

- удаляются полностью дублирующиеся записи;
- исключаются записи без района;
- некорректные координаты `-1` не участвуют в вычислении средних координат;
- справочник `offense_codes` приводится к одной записи на `CODE`;
- `crime_type` определяется как первая часть `NAME` до символа `-`;
- справочник кодов подключается через broadcast join.

Для вычисления `crimes_monthly` преступления сначала агрегируются по району, году и месяцу, после чего рассчитывается медиана месячного количества.

Для `frequent_crime_types` используется оконная функция `row_number()` с ранжированием типов преступлений внутри района.

## Требования

- Python 3.12
- Java 17
- Apache Spark / PySpark 3.5.9
- `uv`

Зависимости проекта находятся в `pyproject.toml` и `uv.lock`.

Установка:

```bash
uv sync
```

## Исходные данные

В каталог `data` необходимо поместить файлы:

```text
crime.csv
offense_codes.csv
```

Файлы исходного датасета в репозиторий не добавляются.

## Запуск

Из каталога `spark_boston_crimes`:

```bash
uv run spark-submit \
  --master 'local[*]' \
  src/boston_crimes.py \
  --input data \
  --output output
```

Пути к исходным данным и результату передаются параметрами:

```text
--input   каталог с crime.csv и offense_codes.csv
--output  каталог для результата
```

Приложение не содержит привязки к локальным абсолютным путям.

## Результат записи

Spark создаёт каталог `output` с одним Parquet data-файлом (кол-во строк небольшое)
